# SLE-3 C4 Architecture

This folder contains the C4 architecture diagrams for the **BFS vs DFS Graph Search System**.

## Files

- `SLE3_C4_Architecture.drawio` — one editable draw.io file containing 3 pages:
  1. Context Diagram (Level 1)
  2. Container Diagram (Level 2)
  3. Component Diagram (Level 3 — BFS Search Module)
- `C4_Context_Diagram.png` — PNG export/reference for the Context diagram.
- `C4_Container_Diagram.png` — PNG export/reference for the Container diagram.
- `C4_Component_Diagram.png` — PNG export/reference for the Component diagram.
